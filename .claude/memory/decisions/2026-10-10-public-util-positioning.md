# 2026-10-10 定位裁定：公共 util，剥离宿主业务仓关联

## 背景

0.1.0 评审后讨论库定位——此前「命名统一」「日志双轨收敛」等事项被「是否存在存量下游」阻塞。需求方裁定（原话要点）：cutils 作为**公共 util** 使用，不再考虑旧宿主业务仓，工程内所有相关痕迹清除。

## 决策记录

1. **定位**：公共工具库（对外提供），无存量下游迁移包袱；pre-1.0 破坏性窗口仍然有效。
2. **痕迹清除**：CLAUDE.md（3 处）/ checklist.md（2 处）/ `.claude/memory/`（2 处）/ `docs/superpowers/` 6 个历史文档（13 处）改通用表述（「宿主业务仓」）；CLAUDE.md.bak 删除（未跟踪文件，需求方确认）。代码侧本就零残留。
3. **连锁解锁**：命名统一（`UUIDUtils`→`UuidUtils`、`KeyBoardUtils`→`KeyboardUtils`、Util/Utils 双轨收敛）不再有下游阻碍，仅受 pre-1.0 窗口约束，待排期。（已于同日 0.2.0 执行：9 类全统一 `*Utils`，文件名与顶层实例名不动，见 CHANGELOG 0.2.0）
4. **日志双轨定位**：`log/` = 轻量打点薄封装、`log_collector/` = 完整采集管线，两者共存；`log/` 被 6 个内部模块引用（net/file/sp/device_info/system/json），**不可废弃**。

## 影响

- 公开 API 稳定性按 CLAUDE.md §十纪律面向未来消费者执行；兼容面讨论不再引用旧宿主仓。
- 下一次破坏性命名调整走 pre-1.0 窗口批量做，CHANGELOG 写迁移说明。
